# GAMECHO 🚀  
[🔗 Voir le site en ligne](https://gamecho-front-fnnu4r525-mayrones-projects.vercel.app/)


## Description  
Plateforme interactive permettant de découvrir, noter et ajouter des jeux vidéo en wishlist.
- Interface en React.js, intégration de l’API RAWG pour récupération des données.
- Gestion des utilisateurs et persistance des données avec MongoDB / Mongoose.
Techno : React.js, Css, webservice RAWG, Express, Next, Mongoose, Node.js, MongoDB, git(hub).
